## FINDINGS

本次未發現應阻擋此候選差異的缺陷。

1. **Primary 探索語義保留成立，限真 projector 的一致 Observation。** 原 unknown boundary seed 0 對 known 端點的最短路，第一次進入 unknown 就已到達 boundary；前段必經 known 可走格。改成 known adjacent frontier seed cost 1，可保持這個 potential。source 被已知友軍占據時會排除；新增 sourceCosts 分支未把占據格當可達 source。實測同時核對代表 tile／weight 不因表示法改寫；16 個 primary 可達案例的實際選擇與 R3 一致。這不是對任意手造、不符合 projector 契約的 Observation 作等價保證。
2. **新探索與偵巡路徑的資訊邊界完整。** 新 weighted helper 只擴張 terrain 非 null 的可走格；vantage 只用 unknown 的幾何位置及真實 UNIT_STATS sight／pathfinding 加成，不看 hidden terrain、site 或 enemy。fallback 以該 unit 的 primary 地形可達性決定，不會因別的 component 有 primary 而封住本 component。既有 site/enemy/relic 目標政策未被額外改寫。
3. **確定性與狀態界線完整。** informationBySight、reconComponents、patrolFields 全部位於單次 chooseAction 呼叫；沒有 module-level memo、歷史重建或跨回合資料。偵巡 phase 只使用已在 Observation 的 ownTurns、unit ID、尺寸與 sight。新目標不修改 Observation；回傳仍是 legalActions 的複本。真 applyCommand 反例驗證了合法性與揭露結果。
4. **測試範圍誠實但有限。** 新10測試涵蓋中央山圈未知、不可達 vantage、occupied vantage 合法繞路、targetless recon、全可見 component 等待、戰術優先與 Fog／確定性；有些既有 assertion 只驗初始方向，本次另以跨 component 真命令補驗。沒有把通過小樣本當成一般策略完備性或終局率證明。
