# PROJECT-4X · D2 動畫與微動態規範 (D2 MOTION SPEC)
## 動畫預算：10% Restrained Cinematic Animation

### 1. 核心動態哲學 (Principles)
* **真實事件驅動**：任何動畫只能由經過合法驗證的命令回傳事件驅動，絕不用動畫自行預測未探索敵軍或決定戰鬥勝負。
* **零操作阻礙**：動畫不得鎖死玩家的操作輸入或相機平移。
* **尊重系統設定**：支援 `prefers-reduced-motion: reduce`，在此模式下立即切換為即時完成狀態。
