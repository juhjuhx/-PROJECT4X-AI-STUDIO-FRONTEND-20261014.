# PROJECT-4X 風格聖經 (STYLE BIBLE)
## 視覺規範與美術實施細則

### 1. 等角視角與投影規格 (Isometric Projections)
* **網格投影**：2.5D True Isometric (2:1 比率)。
  - 地塊寬度：`tileW = 76px`
  - 地塊高度：`tileH = 42px`
  - 水平步進：`wx = (x - y) * (tileW / 2)`
  - 垂直步進：`wy = (x + y) * (tileH / 2)`
* **光照模型 (Consistent Lighting)**：
  - 主要光源：來自左上方（North-West，模擬清晨斜陽）。
  - 頂受光面 (Top Diamond)：高明度主色（反射天空環境光）。
  - 左側面 (Left Facet)：中間調（受漫反射補光）。
  - 右側面 (Right Facet)：深陰影色（背光面，呈現厚度與量感）。
  - 地面接觸陰影 (Ambient Occlusion)：橢圓暗色透明投射（`rgba(15, 30, 25, 0.35)`）。

### 2. 地形元素實體化標準 (Terrain Standards)

#### A. 平原 (Plain)
- 不是無聊的平面綠塊；具備實體厚度切面（9px 立體地盤下緣）。
- 頂面繪製自然質感的草葉叢與三葉草斑點，地表有細微的晨光微塵。
- 移動提示為光亮金色菱形符標，與草地形成鮮明對比。

#### B. 森林 (Forest)
- 具備高低起伏的立體樹冠（Multi-tiered Canopy）。
- 針葉林採幾何切面錐形，受光面（綠松石白高光）與背光面（墨綠深陰影）清晰對立。
- 樹幹以深褐木質立柱支撐，底部附帶自然的樹蔭遮蔽。

#### C. 山脈 (Mountain)
- 雄偉多面體岩石巨峰，具備清晰的岩壁稜線。
- 山頂覆蓋高海拔晶亮積雪（Alabaster Snowcap）。
- 高度經精準戰術調校（高度控制在 42px 內），絕不遮擋鄰近單位的血條與選取框。

#### D. 水域 (Water)
- 雙層梯度：深水淵潭（`#2c515c`）至淺水海岸（`#598a96`）。
- 邊緣帶有舒緩柔和的白色海岸浪沫（Shore Foam Lines）。
- 輕微的幾何水紋漣漪，呈現活水動感而不造成視覺疲勞。

#### E. 迷霧 (Mist)
- 未探索區塊（Unknown）：如沉睡於黑曜石海的未知基座，邊緣雕刻有星軌符文微光。
- 已探索陰影（Explored Fog Veil）：古代墨染薄紗（`rgba(15, 28, 25, 0.42)`），清晰提示「曾被探明但當前無即時視野」的歷史記憶狀態。

### 3. 建築與聚落識別 (Settlement & Monument Visuals)

* **歷史首都 (Dawn City / Duskstar City)**：
  - 雄偉的三層巨石城堡要塞，城垛、護城基岩、天際瞭望塔樓。
  - 頂部配有精金星穹圓頂（Gilded Dome）與高聳的文明主旗（長幅雙尾旗）。
* **一般據點 (Fortified Outpost)**：
  - 兩層石木結構監視所，具備射手射孔與防禦性欄柵。
* **荒野村落 (Wilderness Village)**：
  - 木構茅草圓屋，帶有自然石頭地基與平和的中立灰白信標旗。
* **遠古遺跡 (Ancient Megalith)**：
  - 懸浮的風化巨石方碑，中央刻有金黃色遠古神經脈絡符文，週邊環繞星點粒子。

### 4. 兵模微縮規格 (Miniature Figurine Specs)

* **基座徽印**：
  - 實體微縮兵棋厚底座（Bronze Beveled Base），直徑 28px。
  - 曦原城邦：暖金飾邊 + 翡翠石底。
  - 暮星盟約：深赤紅邊 + 曜石黑底。
* **兵種造型剪影**：
  - **步兵 (Infantry)**：方盾、短劍、羽冠重盔。象徵防線與衝鋒。
  - **斥候 (Scout)**：疾風披風、獵弓/短匕、羽毛風鏡、身形前傾。象徵速度與探索。
  - **弓兵 (Archer)**：大曲度長弓、腰間箭袋、拉滿弓弦的戰術戒備姿態。象徵遠程支援。
* **狀態刻度**：
  - 採用古老石刻血量條（Stone Slate HP Bar），高血量為青翠翠玉、中血量為琥珀蜜黃、瀕危為赤朱硃砂。
  - 耗盡行動力（Moved + Acted）：微縮兵模降下待命姿態，頂部顯示肅穆的休整印記。
