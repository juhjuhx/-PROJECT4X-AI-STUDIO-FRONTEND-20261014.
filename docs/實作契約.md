# MVP 0.1 自主實作契約

2026-10-11 最新使用者指示：直接建置 MVP；工程、規則細節與審查授權由代理自主處理。既有確認裁決保留，以下為可更改且版本化的初版工程預設，並非新增主創裁決。先前文件「逐項請示／等原型來源才開發」不再阻塞本版本。輸入 ZIP 僅含文檔；本目錄是全新独立 source，不冒充未取得的舊原型。

## 目標與界線
24×24、1人對1AI、四向移動、三兵種／三科技／金幣、迷霧／村莊／立即遺跡選擇、軍事征服／流亡／主動建新中心、保存與重播。玩家情緒為未知與發現。完整文化、外交、能源代謝、網路多人留後續。45–90分鐘為待真人驗證的目標，不增設淘汰倒數。

## 工程預設
TypeScript＋Vite＋Canvas2D，零執行期第三方依賴。獨立純規則核心承接未來後端權威；本版在本機執行，不增加無需求的伺服器資料庫。Canvas2D可原生執行2.5D多邊形、mouse/touch；與Pixi/Phaser比較後選無GPU啟動與framework依賴的初版。渲染替換只需Observation契約。地圖seed顯式設定，版本固定；AI只讀Observation與投影後合法候選。原創程式绘製地圖，不複製Polytopia資產。

## 已確認規則
活單位或己方據點任一仍在即可續玩；二者都零才淘汰。歷史首都不等於當前政治中心。失去中心流亡，持續控制據點跨過完整對手回合後，免費主動建立新中心；不自動復辟，不重設行動與招募。遺跡首次己方回合可見授權，立即進入必答階段：只接受ResolveRelic，無未知格禁用情報仍可4金。情報最多3仍未知地形格，不附敵軍情報。

## 其餘初版預設
人類先手；遺跡情報按距離遺跡曼哈頓距離、y、x穩定排序。城市掩護按防守者控制判斷。Move目的格由核心尋最短合法四向路徑；單次移動不穿越單位。科技Farm5／Archery6／Pathfinding4；Recruit4／5／6；初始8金，第一己方回合不收入，後续每据點2＋Farm1。對手回合序號在EndTurn才完成，用於持續控制資格。所有合法命令版本+1；錯誤原狀不變。成功requestId同payload重送無副作用，不同payload拒絕。

## 切片與驗收
1. 契約／地圖／單位／回合 → 核心正反邊界測試。
2. 探索／遺跡／流亡／重建／AI → 规则整合＋迷霧隔離測試。
3. 原創2.5D介面／mouse/touch／保存重播 → 桌面與模擬手機浏览器。
4. OCR檔案範圍＋獨立審查 → 修復→最終型別／測試／build／headless／GUI。
5. 交付可啟動版本與證據；真人整局與實體手機保持未驗，不由AI代填。

## 分工
Root owns契約／scaffold／整合／文檔／證據／發行。Gameplay owns src/core/除types.ts及核心測試。UX owns src/main.ts、src/ui/及styles。獨立QA owns tests/review.test.ts與scripts/headless.ts，讀其他source後回報，不跨寫。共享types由Root更改。

## 介面修訂與觀測
chooseAction(Observation): Action|null；非己方回合與terminal的空合法候選回null，driver停下，沒有非法EndTurn補送。GameState新增surveyed：正常視野曾見的格，與僅情報揭地形explored分開。據點視野為本格與四向相鄰（半徑1）。初版4個遺跡，含雙方各一個安全早期遺跡；此為自主MVP探索配置，非把原TARGET冒稱已主創確認。

診斷回答三個問題：哪個seed／版本／command開始錯？保存與續局何時分歧？哪一段操作延遲？本機命令歷史與匯出回放供第一項，save重建與逐筆reject供第二項，headless及browser證據的P50/P95供第三項。不接遠端分析或付費AI，不在畫面顯示隱藏敵方command內容。canonicalHash是非密碼學FNV64 gameplay checksum，不包含protocol歷史／去重ledger；讀檔仍全量重建並完整比較包含ledger，不能拿checksum當安全簽章。规则g1-ccts-1連同生成器、RNG及canonical算法為此版凍結bundle；後續更動必須升版本，舊存檔不默默套新規則。
