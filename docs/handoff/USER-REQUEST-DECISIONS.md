## 本次十項世界方向

1. 不同文明可以擁有完全不同的技術與生存需求。
2. 局域物理規則與外域能量交換可以並存。
3. 文明之間可以存在極端軍事差距。
4. 弱小文明仍可以藉由神器、研究、地形、外文明協助及資源交易取得翻盤機會。
5. 文明可以徹底轉型。
6. 文明滅國不代表文明消亡。
7. 世界具有唯一可逐步揭露的起源真相。
8. 荒誕設定必須遵守內部因果。
9. 不同文明可以感知到截然不同的世界表象。
10. 進入星際後，原有世界仍持續運行。
