lockfile 共93筆工具／平台依賴：MIT55、Apache-2.0為24、MPL-2.0為12、ISC1、BSD-3-Clause1；沒有缺少license欄位。MPL-2.0的12筆是 lightningcss 1.33.0與其平台套件（Vite開發工具鏈），不是遊戲執行期載入模組；因此不能把整個工具鏈一概寫成MIT。這份計數是lockfile聲明，重分發時仍依實際LICENSE／NOTICE及發布範圍處理。

## 官方接口研究與採用限制

[Vite TypeScript 文件](https://vite.dev/guide/features.html#typescript) 明確區分 transpile 與 typecheck；本專案 build 先執行 `tsc --noEmit`，再 Vite build。[TypeScript noEmit](https://www.typescriptlang.org/tsconfig/noEmit.html) 的檢查不產生 JS，符合獨立建置工具流程。tsx／Vite 能執行或轉譯不代表型別通過。

測試採 Node 原生 [test runner](https://nodejs.org/api/test.html)，透過 tsx 執行 TS。獨立測試以公開契約及正／反／邊界／整合結果為 oracle，不複製核心驗證分支。Headless 用 `chooseAction(observe(state, active))` 提案，再交同一 `applyCommand`；不向 AI 傳全圖真相。

Canvas2D 只接 observation 繪圖。地形、單位、據點與遺跡以自行撰寫的幾何程式繪製；camera／animation／GPU 資料不作規則權威，不寫入 canonical hash。是否實際滿足資料邊界由 source 審查及 GUI 測試另證。

Web Storage 是同 origin 的本地儲存機制；瀏覽器配額／存取錯誤仍須由 UI 顯示。它不是雲端後端，也不是抗本機檢視的保密邊界。載入先完成版本、內容與世界語意驗證，再發布唯一權威狀態；失敗不能清空既有槽位。正式保存續局／replay 另有獨立負例。

## 參考／未採用

PixiJS、Phaser、boardgame.io、Freeciv、Unciv、Zod、fast-check 目前不在本專案 dependencies，也不以研究引用視為已複製程式。完整文化引擎、LLM API、外部 AI 模型、Worker／WASM、雲端資料庫及網路多人未加入。未採用專案的授權不能替代日後實際引入版本的 LICENSE 盤查。

`official-code-review` 已讀，但此工作沒有 PR，沒有套用其 GitHub／PR／發評論流程。`code-review-excellence` 用於本地獨立 source 審查。`open-code-review-delegate` 僅作檔案納入／規則解析；它不呼叫額外 LLM，成功 exit 也不代表遊戲正確。最終結果須記 reviewed／excluded／skipped 與補審理由。

## 資產來源與交付義務

原創 Canvas 程式資產由本專案生成；不使用 Polytopia 的圖、UI、圖示、字型、聲音、地圖或程式。起始目錄未加入外部圖片、影片、音樂或字型檔；最後發布前仍需掃描 source／dist 及網路載入，核對沒有新外部素材。系統字型名稱只使用使用者裝置已有字型，不打包字型檔。

開發工具及其傳遞依賴的完整 LICENSE／NOTICE 保留在本地安裝套件；若重分發工具、source 附帶第三方程式或發布產物包含第三方片段，須隨實際發布範圍保留相關 notices。原創專案程式的對外授權仍由使用者決定；不因 MIT／Apache 工具就自行宣布整個遊戲開源或推送公有 repository。
