# 23｜設計裁決表：確認／提案／待驗證／尚需主創取捨

## 已由使用者確認的方向 [REQ]
- 原創、易上手的回合制戰棋/4X，主要借鑑 Polytopia 的抽象操作精神而非內容；斜視微縮、可用 2D 或 2.5D。
- 前期以探索與征服為主、A 優先；B 外交與 C 文明經營併入長期，但不使 MVP 爆炸。
- 中後期希望低微操、軍團戰線與高效能；World 很大、資源和科技多分支、可通往星際。
- **非線性世界**：起始類似中古奇幻，但地圖另一端可能有現代、修仙、機械、賽博、異星蟲巢及超現實迷因文明；核心是文明生存。
- 開源優先且要能持續以 AI Agent 建置、獨立審查、可換美術、跨平台。

## 由本次設計者暫定 [PROPOSAL]
- 背景原因保持謎團、不在 MVP 透露最終宇宙真相。
- First Playable 24×24、2 方、3 種兵、3 科技、1 異常據點事件、征服獲勝。
- 科技是平行領域 DAG，不以年代為強弱衡量；新內容用 versioned pack 加入。
- 初期核心 TypeScript headless；RendererAdapter 與平台 Shell 可替換；先測試再評估 Rust。
- 簡易事件選擇和 fog 知識階段，由玩家操作自發揭露未知世界。
- 後期文明視覺與科技主題可含荒誕迷因，但正式素材需原創、可溯源與自洽。

## 需實際測試 [VERIFY]
- 24×24 是否能產生 3 個以上值得回憶的決策與重玩意願；事件是否有策略影響。
- 斜視逆映射在手機手指點擊正確率、螢幕可讀性、AI 回合延遲。
- Pixi 8 vs Phaser 4 可維護度／耗電／CPU/GPU；Worker Transferable 成本；Rust 是否有必要。
- 全套素材／npm／程式碼 LICENSE 和 SBOM；交叉平台打包成功。

## 可供一次決定的創意問題（不阻塞做設計文件）
**唯一目前可能改變第一個 MVP 內容的問題：異世界驚奇在第一局應是「安全、神秘的遺物」，還是「會主動威脅城邦的未知文明」？**
- A（預設）：安全但有代價的未知遺跡。最簡單、專注基本征服迴圈，異常提供選擇而非第三個敵人。
- B：中立機械／異獸駐地；有可能交戰，複雜度中等。
- C：真正的第三個異世界 AI 文明；增加地圖／平衡／交涉／AI 規則成本，不建議 G1。

如未補充，以 A 作 first playable，B 放 G2，C 放 G3+。其餘可由設計師在後續根據試玩數據決定，不再將「時代風格三選一」重問使用者。
