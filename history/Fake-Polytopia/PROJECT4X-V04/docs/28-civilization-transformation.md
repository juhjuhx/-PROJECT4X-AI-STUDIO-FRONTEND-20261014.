# 28｜文明轉型、分支與身份連續性 v0.4

**使用者決策 [CONFIRMED]**：文明可能由零修城邦徹底轉型為機械文明，也可能混合技能與制度；不是只能修改幾個加成。

## Civilization != Government != Species != Technology
- `CivilizationIdentity`: 自我認同、傳承、語言、集體記憶、文化圈、長期行為；可在國家崩解後延續。
- `Polity`: 政權/政府/國家/土地行政管理，可能統治多個文明；政權不一定代表文明。
- `PopulationCohort`: 人口群體/機器社群/蟲群，具有所屬文化、地理位置、能力與轉化政策；不在 MVP 模擬單個人口。
- `CapabilitySet`: 技能、設備、知識及實作能力；不依國家名稱硬編碼。
- `FactionController`: 玩家/AI 在本局可發布命令的主體；可更換政體或流亡控制模式。

## 從學習到蛻變
`CONTACT -> OBSERVE -> RESEARCH_FRAGMENT -> ADOPT_PRACTICE -> INSTITUTIONALIZE -> TRANSFORM`。技術跨文明轉移不是相遇即解鎖；需要物質、語言與知識解讀、工廠或儀式，可能讓部分內部派系反對。任何階段都有權衡與可中止性。

## 四種轉型效果
1. **裝備級**：獲得機械器物，不改文明身份。
2. **能力級**：研發能源轉換與維修技術，可擴充兵種。
3. **制度級**：社會重心改變，例如從行會轉為機械工坊聯邦，影響外交與經濟。
4. **身份級**：文化、神話與制度重組，文明正式改名/分裂/融合。舊身份不必自動清零；產生可追溯的歷史譜系。

## 範例：河谷城邦 → 金屬信徒 → 星械同盟
河谷軍在山脈遇見停止運作的自動城市。獲得零件並不代表瞬間會造電腦；他們必須選擇保留傳統農業、借用機械外骨骼、或讓祭司與工程師共同建立新制度。初始的神靈護符可能演化成科技宗教，或被世俗化。一百回合後，『河谷城邦』不復存在，但其歌謠、符號與制度仍可能存在新文明中。

## 可變與不可變
可變：能力、資源需求（附適應成本）、生產配方、單位類型、視覺、制度、外交偏好。不能任意改：既有命令合法性、過去已發生的事件、神器內核規則、玩家可見歷史與已承諾的戰爭結果。Faction ID 穩定，歷史關聯透過變遷事件；存檔保留 lineageId。

## 防止無限堆疊成萬能文明
能力衝突/互斥制度、維護成本、物質不可替代、人口適應週期與科技依賴。轉型後可能失去舊優勢，世界中不存在『任意能力全部免費兼得』的最優文明。

## 實作邊界
G1 不提供轉型 UI；G1.5 只測同一個 CivilizationDef 在保持 ID 的前提下更換有效 recipes 和 survival needs，資料不依某一種固定種族。G3 才新增正式研究/接觸，文化身份變更推遲至後續。
