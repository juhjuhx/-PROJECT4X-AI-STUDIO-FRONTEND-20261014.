# 35｜G1 First Playable 與 G1.5 非對稱文明先驗探針 v0.4

## 核心交付界線（不得偷換）
**G1 是真人可玩**：24×24、1人+1合法 AI、3兵種、3科技、金幣作抽象費用、可奪中立村莊、Fog、簡潔斜視 UI、首都征服、異常遺跡二選一、存檔／重播。**v0.4 沒有擴張 G1 的 UI 功能，也沒有把 10 種文明塞進 G1。**

**G1.5 是 headless 驗證**：世界底層將來能支援三文明不同代謝、配方／能源、反制神器、出生地可生存性，避免直到 G5 才發現 v0.3 architecture 不可拓展。它不是 G1 的先決條件；但在宣布『擴張成真正異文明玩法』前必須通過。

## G1 再補強：AI 不等於 random legal action
- 優先序隨局面變更：守首都 > 避免立即致死 > 可達中立村 > 適時招募與研究 > 推進敵方首都；必須有非純隨機的可讀 `decisionTrace`，權重是可測提案而非固定必勝腳本。
- `legalActions` 提供可行動集合，`AIPlanner` 根據 Observation 做威脅／收益評分。重播可用固定節點預算；不得依 wall-clock 累積採樣多少就得出不同結果。
- 驗收場景：可佔中立村不會盲目亂走；敵部隊已逼近首都且有可防守手段會考慮防守；近在咫尺的首都不因偏好貯金而永遠不攻。三例均可被 deterministic fixture 判定。

## G1.5 三文明 fixture（無前端）
| Fixture | 輸入 | 通過行為 | 必須失敗的反例 |
|---|---|---|---|
| F1 生存差異 | 同一張地圖，農業/修行/機械 Profile | 各自能辨識不同的生存瓶頸與資源價值 | 將 gold 當所有 upkeep 的萬能替代 |
| F2 配方轉換 | 工坊與有限輸入材料 | 合法扣/產、有限流量、byproducts | 輸入不足仍生產／同一材料雙花 |
| F3 反制神器 | 技術碾壓敵軍+有線索的器物 | 特定環境啟動使局部戰局可反轉 | 任意武器每次均可一擊必殺 |
| F4 起點公平 | 100 個以上固定種子；後續 10k 種子 | 都能找到最低生存輸入與至少一條擴張／反制途徑 | 困死在無產出的孤島 |
| F5 文明轉型 | 同文明獲得機械配方能力 | 身份 ID 與既有史料不變，需求和能力可改 | 身份硬編碼關閉新配方 |
| F6 難民/文化 schema | 領土被清零 | `CivilizationIdentity` 能持續被引用 | 城市消失即清掉文化 ID |
| F7 事件與 Fog | Artifact 在迷霧後、AI 發現 | AI 只由自身線索得知、單次獎勵 | UI/debug payload 漏出隱藏 ID |

**驗收**：上述是測試規格，不是宣稱已執行。每份結果必須列 seed、核心版號、規則包 hash、測試命令/退出碼和生成的回放檔。不能以 agent 自言自語『有趣』代替真人完成對局。

## G2 和 G3 的玩法目標
G2：20 單位對照攻城，同一 `ArmyDirective` 降低手操而不剝奪控制；玩家能通過1種非標準戰術推翻更高戰力的局部敵人。
G3：兩種已確實互動的異文明生存路線+一種外交交易，在至少一局中改變玩家的行動；保留 4 文明 48×48 大型 MVP 的逐步擴張可能。

## 玩家故事測試（非機械模擬替身）
A 玩家先攻城後經濟發展可勝；B 玩家先擴城研究仍可勝；C 人類在遺跡前選資金/情報各會改變下一輪決策。用錄影、操作數、事後具體問題觀察；一局不好玩優先修規則，不急著堆新文明。
