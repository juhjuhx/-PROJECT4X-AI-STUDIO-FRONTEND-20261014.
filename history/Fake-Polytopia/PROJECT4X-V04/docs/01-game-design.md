# 01｜Game Design Document v0.1

## 工作標題與世界
代號 **PROJECT-4X**（尚未取正式名稱）。原創架空群島／大陸世界，國家從散落聚落起步，因地形與歷史形成不同發展方向。故事透過地圖事件、外交關係、城市成長和戰爭留下的痕跡自然形成，不使用昂貴的長篇劇情線作核心依賴。

## 玩家循環（30–90 秒一個典型回合，僅設計目標）
`觀察地圖 -> 評估首要威脅／機會 -> 分配城市產出 -> 移動與交戰 -> 研究／政策／外交 -> 確認結束回合 -> 看見對手反應及世界事件`。
玩家能隨時查看行動預測（可達範圍、戰鬥可能傷害、道路連通、外交影響）；每次選擇需有相應成本。

## 遊戲模式
- **短局**：24×24、雙勢力，教學與 15–30 分鐘方向；無保證遊玩時長。
- **標準**：48×48、4 勢力、預計 45–90 分鐘，第一版主要平衡場景。
- **廣域**：96×96、4–6 勢力，解鎖後且性能驗收合格才發布。
- **極大型（研究）**：128×128／256×256；優先視覺分塊、局部更新、非同步 AI，性能數據決定是否提供。
- **勝利後**：保留 GameState、VictorySnapshot 並進入 `POST_VICTORY`，關閉再次結算勝利，玩家選沙盒持續經營；多時代事件未列 MVP。

## 核心快樂來源
領土前線、遠交近攻、有限資源下多線選擇、地形阻斷、文明發展獨特性、一次外交背盟造成的連鎖反應。每個「深度」系統都必須讓玩家產生可解釋、可逆轉、可預見的戰略選擇。

## 機制與 MVP 邊界
| 子系統 | 玩家可見行為 | MVP v0.1 | 升級方向 |
|---|---|---|---|
| 地圖／迷霧 | 發現山脈、河流、聚落 | 方格地形、seed、探索／已見／不可見 | 多層高度、生態帶、海域 |
| 城市／經濟 | 擴張城市及分配建設 | 城市級 1 策略槽＋金幣 | 城市特化、貿易網絡 |
| 部隊 | 步騎弓克制與佔領 | 6 類、傷害預覽、移動消耗 | 海戰、攻城器械與英雄 |
| 科技 | 3 樹線、有限解鎖 | 9–12 技術節點 | 多文明不對稱科技 |
| 外交 | 交涉、停戰、聯盟 | 和平／交戰／同盟，簡單聲望 | 條約／停火期限／代理戰爭 |
| 信仰／政治 | 教義改變城市與外交 | 每文明最多 1 條教義＋1 政策槽 | 宗教傳播、政治制度 |
| 天氣／道路／補給 | 地形選擇影響行軍 | 天氣輪替＋道路補給「輕」版 | 供應線截斷、極端事件 |
| 勝利 | 三種路線形成競爭 | 征服／聯盟霸權／文化繁榮 | 科技、貿易、信仰等 |
| AI | 可見且合理的對手 | 3 性格＋啟發式策略 | 樹搜索／自我對戰評測 |
| 跨平台 | 用滑鼠及觸控玩 | Web＋桌面＋Android/iOS 驗證路徑 | 商店上架、同步、多平台成就 |

## 回合安排
開局隨機選文明與地圖 seed，先顯示玩家出生地與周邊 2 格，鄰近至少一處中立村落，避免陷入無路可走地圖；單位行動與城市決策可自由次序，按「結束回合」後依固定座位順序結算經濟、城鎮事件、國際關係與季節；所有同回合觸發事件需明確且可重放。

## 教學和 UX
首局只顯示「移動」「建立／占領」「結束回合」核心控件，科技、外交按里程碑逐步亮起；所有狀態能從地圖上的圖標或情境式資訊面板快速辨識。桌機右鍵／手機長按開啟上下文說明，鍵盤 Esc 可離開對話。

## 不直接移植 Polytopia
借鑒規則的抽象設計概念（低點擊、科技驅動擴張），不使用官方名稱、種族、圖像、模型、地圖、聲效、原始文案、精確數值表或受限原始碼。遊戲名稱與視覺識別需獨立建立。
