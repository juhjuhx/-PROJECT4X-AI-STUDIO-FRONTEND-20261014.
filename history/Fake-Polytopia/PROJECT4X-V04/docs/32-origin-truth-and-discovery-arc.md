# 32｜唯一宇宙原點、書寫者與可揭露的真相 v0.4

**使用者已確認的創意方向**：宇宙要有單一最終可揭露的起源；其神話核心可以極度荒謬——一位想要簡單策略遊戲的設計者，因不斷增加願望，反而創造了無限龐雜的世界。**本文件中的人名、裝置名、運行細節屬 [DESIGN-PROPOSED]；可供外部 Agent 批判，尚不是鎖定的文學正史。**

## 正史雛形：願式織機 The Wish Loom
最初『書寫者／The Draftmaker』只想擁有一個能讓小小文明存活、探索並互相對抗的棋盤。當他許下『有更好的外交』『更真實的物質』『更強的敵人』『更遙遠的未來』『更多傳說』時，織機沒有捨棄舊版本，而是把每次迭代的**相容與不相容規則都物化成新區域、族群與世界層**。文明各自相信自己的物理、宗教與歷史是唯一現實；但它們其實是同一個持續編譯的世界中的分支。

這不是遊戲中真正的即時 LLM 可以隨時增加規則；『世界編譯』是固定的 fiction canon，玩家對局仍由已版本化的法則運行，確定性、資源限制、反制與存檔完全有效。『設計者』不是一個會出現在 UI 向玩家喊話的真人，也不借用任何既有策略遊戲的商標與專屬設定。

## 單一真相、局部多種解釋
- **唯一原點**：書寫者/織機的第一次願望與其持續迭代。該秘密可被世界中多方證據逐步推導；不是從頭到尾保持永遠模糊。
- **不同文明的神話**：宗門稱之為天工、機器族稱之為起始編譯器、農業王國認為是造物神話。它們都握有真相片段，而非某族完全正確、其他皆錯。
- **後續真相延伸**：起源被揭露後，玩家仍可研究織機接口的物理邊界和更高層世界，繼續生存與探索。

## 漸進揭露（玩家不需跟固定章節走）
| 階段 | 偶遇表象 | 可解釋內容 | 機械後果 |
|---|---|---|---|
| First Fracture | 未知金屬、語言、異常方格 | 地方歷史不完整 | 遺跡：資源或情報，G1 |
| Contradictory Archives | 修行年代與機械記錄衝突 | 不同文明記錄有共同符號 | 接觸與翻譯獎勵，G3+ |

| Origin Event | 願式織機/書寫者留下的首願 | 所有文明源於持續增願的世界 | 遊戲主線的長期真相，但**不強制結束沙盒** |

## 不走一本道
每種線索有 `clueGroupId`, `prerequisites`, `interpretations`, `knowledgeDelta`；可以通過不同順序的考古、貿易、對話、戰爭殘骸、技術研究拼湊。核心真相至少有三種不同來源，禁止依靠唯一 missable 事件。

## 故事張力
真正的恐怖不是『被設計』，而是：眾文明的存續願望可能互相矛盾，織機把它們都當作必須保留的要求。世界因此無法停下擴張，文明只能在互相理解、改造或消滅之間選擇。終局不該否定玩家的國家歷史與戰略選擇。

## 正史防漂移驗收
- 發現碎片不能直接給玩家完整世界設定集或公開隱藏敵國科技；早期存在嘲諷性『介面符號』也不能直白引用真實遊戲開發者。
- 同一局線索、世界真相和神器本質由 seed+ruleset 固定；不可由 LLM runtime 即興改寫。
- 笑點具有內部代價與用途（例如『把事情命名為門，門就必須具備進入與出口條件』），不許無成本 omnipotent 迷因。
