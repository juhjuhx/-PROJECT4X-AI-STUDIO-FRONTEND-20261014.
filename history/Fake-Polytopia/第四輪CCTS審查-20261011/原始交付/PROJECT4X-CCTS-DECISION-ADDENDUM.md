## 0. Executive decision｜這次改了什麼

PROJECT-4X 不再假設「國家 = 文明 = 玩家勢力」。玩家可失去現有國家，卻以殘軍、流亡人口、商業網絡、教派、游牧同盟、思想／文化影響力持續生存；也可不恢復舊國，而是另外建國、奪取他國政權，乃至建立非領土政治秩序。

**最新主創裁決 `C` [USER-CONFIRMED]：政治控制權與文化影響力彼此獨立、可以交錯並存。** 征服者可以被被征服者同化；沒有政權的文明可以支配一個國家的觀念；玩家取得行政機器不會瞬間轉換所有居民的文化；文化傳播也不必自動將政府主權轉移給傳播者。

> **不可誤解為**：玩家永遠不會輸；文化就是一個百分比進度條；直接征服 = 政治篡奪；文明不斷分裂沒有代價；G1 必須一次實作所有政治、人口、宗教與文化系統。

## 2. 核心本體論｜World、Civilization、Polity、Organization、Player

### 2.1 五種概念不應合併

- **WorldTruth / 世界真實狀態**：物件、人口、組織、資源、領土、因果關係、事件與世界起源等唯一權威資料。不能因觀察文明不同而任意改寫。
- **CivilizationIdentity / 文明傳承身份**：持續變遷的歷史、價值觀、語言、知識和習俗，以及對其傳承關係的追蹤；一個文明可以跨多個政權延續，也可能分裂、融合。
- **Polity / 政治實體**：宣稱／行使某種治理權的組織結構，例如王國、城邦、議會聯盟、蜂巢集體、分散式網路政體；它能有領土，也可能沒有常規領土。
- **PopulationCohort / 人口群體**：居民、流亡者、游牧民、殖民群體或知識共同體。其政治歸屬、文化身份和實際居住地不一定一致；人口不會隨首都事件瞬間消失。
- **Organization / 組織**：軍隊、宗教、財團、地下組織、游擊隊、情報網絡；它可能橫跨多個政權。
- **FactionController / 玩家控制席位**：誰能下達何種合法命令；它可能暫時透過軍隊、政權或組織發揮作用，**不是文明身份或國家本身**。

> 註：以上是長期系統分界；G1 不必立即建立五套完整資料結構。現有 `Faction.identityId`、`lineageId` 可作最低限度語義保留。

### 2.2 四個相互獨立的投影

```text
                  [Canonical WorldTruth]
                            │
              ┌─────────────┼─────────────┐
              ▼             ▼             ▼
       Political control  Cultural reach  Population affiliation
       [政權／領土／官僚]   [認同／制度／宗教]    [人口／遷徙／忠誠]
              └─────────────┼─────────────┘
                            ▼
                  Civilization perception
               [各文明感知／推論／知識]
                            ▼
                   Player observation
               [玩家合法知悉及可操控]
```

※ 上圖是功能與資料投影概念，不意味著 `Population affiliation` 或 `Cultural reach` 可以在 UI 或 AI 中直接當作全知資料。所有對玩家可見的欄位都要遵循權限與知識投影。

### 2.3 政治與文化的四種基本局面 [USER-CONFIRMED 的邏輯推導]

| 國家統治權由誰掌握 | 社會主流文明認同 | 可能出現的事件 |
|---|---|---|
| A | A | 本土政權與本土文化一致 |
| A | B | A 征服 B，但未能文化同化，甚至統治集團逐漸採納 B 的制度 |
| B | A | B 取得行政權，但大多數人口仍遵循 A 文明習慣 |
| 混合／爭奪中 | 多源並存 | 多語聯盟、自治／地下抵抗、混合制度、文化競爭 |

文化不必只有一個「主流」。單一國家內可以多元並存，也可能在軍事佔領下發生持續抵抗。

## 3. Civilizational continuity｜亡國不是終結

### 3.1 玩家可採取的長期路線 [USER-CONFIRMED]

1. **故土復興**：反攻奪回原首都，可能重建原國，也可能改制。
2. **異地建國**：控制其他地區並創立新國，不要求繼承舊國全部制度。
3. **奪取他國政權**：以軍事／政治行動奪取行政機器；既有人民、文化與制度不會立即同化。
4. **文明滲透／融合**：在未接管政權時，透過交流、移民、信仰、教育、貿易影響社會。
5. **非領土化存續**：地下教派、跨國商盟、游牧同盟、分散式網絡。
6. **文明影響型勝利**：國家不在，思想或制度仍成為跨文明主導力量；勝利規則待後續設計。

上述路線**並非互斥職業／固定科技樹**；同一文明可依歷史轉折混合發展。

### 3.2 G1 最小可玩 `ACTIVE → EXILED → RESTORED / ELIMINATED` [設計範圍已確認，細則提案]

```text
   [ACTIVE] — 失去首都且仍有可用殘存勢力 → [EXILED]
      │                                        │
      │                                 ┌──────┴──────────┐
      │                                 ▼                 ▼
      │                         奪回原首都          另尋可合法立足點
      │                                 └────────┬────────┘
      │                                          ▼
      │                                      [RESTORED]
      │                                          │
      └──────────────────────────────────────────┘

           [EXILED] — 失去全部有效延續能力 → [ELIMINATED]
```

- **G1 必做 [USER-CONFIRMED]：** 首都淪陷不必然即終局；殘軍可繼續操作；允許在舊首都或其他據點重建政權，並保留對他國政權奪取的長期設計通道。
- **G1 限縮 [DESIGN-PROPOSED]：** 把「奪取敵方據點／建立新首都」做成軍事奪取後的政權重建。真正的**不靠軍事戰勝而篡奪行政權**留至 G2+；避免將文化與政變兩種不同玩法硬塞入 G1。
- **G1 不做：** 多層人口模擬、秘密宗教滲透、完整文化傳播、貿易網絡與文明同化 UI。
- **待裁決：** 哪些單位算作有效流亡基礎、何時發出 `Eliminated`、是否每次失都皆可流亡、AI 何時追擊殘軍、時間上限是否存在。
- **重要：** G1 的終局要按「最後有效存續條件」重設。原型中「佔首都立刻 `winner=c.actor`」在新裁決下**過時且必須修改**；此文件**沒有修改程式碼**。

### 3.3 政治篡奪與文化轉換不可畫等號

- 政治奪權：取得命令軍隊／徵稅／任命官員／使用行政網絡的權限，其結果是 `PoliticalControlChanged`。
- 文化滲透：居民、制度和知識傳承因可解釋的社會行為改變，其結果是 `CulturalAdoptionChanged`。
- 同一次事件可能同時影響兩者，也可能只影響其中一者；狀態變更及回放日誌應**分別記錄**。
- 不能以「佔領一格土地即全圖文化歸零」或「宗教已成主流即自動奪取首都」當通用捷徑。

### 4.2 建議第一步修改（P0，因勝利規則變更） [DESIGN-PROPOSED]

先僅引入一個**明確且可版本化的戰局生命週期**，不要建空 `Polity` 全家桶：

```ts
// Contract sketch ONLY — not shipped code, naming / data shape require spec review.
type FactionLife = 'active' | 'exiled' | 'restored' | 'eliminated';

  | { kind: 'ongoing' }
  | { kind: 'victory'; winnerFactionId: string; reason: string };

  polityId: string;
  oldControllerId: string | null;

```

G1 僅實作 `cause='conquest'` 的狹窄路徑，其餘 `cause` 保留為規格草圖，不預設可用。不要在任何 UI 或 AI observation 中把全域 `PoliticalControlChanged` 原封轉發，以免洩漏遠方政權變動。

### 4.3 長期模組界面（不要求 G1 實作） [DESIGN-PROPOSED]

- `PolityRegistry`: 政權建立、控制變更、解散、繼承，與文明身份 ID 解耦。
- `CivilizationLineage`: 文明延續、分裂／融合、制度記錄，不因失都而刪除。
- `PopulationAffiliation`: 地區／群體的多來源政治忠誠與文化認同；資料容量上限待研究。
- `CulturalInfluenceEngine`: 透過可追溯事件擴散文化，不能免費無限增殖或毫無反制。
- `PoliticalTransitionEngine`: 戰爭、選舉、王位繼承、政變等政權移轉機制。
- `PerceptionProjector`: 先處理真實狀態 → 感知 → 知識 → 對玩家合法的觀察。
- `VictoryEvaluator`: 終局依模式與可持續勢力條件判斷，不將「國家被征服」硬編成「文明不存在」。

所有變更透過**同一 authoritative reducer / dispatch** 結算，與 v0.4 AGENTS.md invariant 1–10 一致。不得由 UI、AI 或 LLM 直接調整文化狀態。
